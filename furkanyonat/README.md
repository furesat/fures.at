# Furkan Yonat Portfolio

Tek dosyalık statik portföy sitesi.

## GitHub Pages ile yayınlama

1. Bu klasördeki dosyaları GitHub reposunun kök dizinine yükleyin.
2. Repository > Settings > Pages bölümüne gidin.
3. Source: Deploy from a branch
4. Branch: main
5. Folder: / (root)
6. Save

Ana giriş dosyası: `index.html`
